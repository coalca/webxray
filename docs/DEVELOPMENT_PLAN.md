# WebXray 0.3.0 开发与验收计划

## 产品目标

WebXray 0.3.0 是一次界面、交付和文档共同升级。首页必须让没有 Xray 经验的用户立即看懂
后端连接、核心运行、当前节点和代理入口；三种发行版本必须说明能力、权限和平台边界。

## 执行表

| 阶段 | 交付内容 | 验收方式 |
| --- | --- | --- |
| 产品架构 | 状态优先首页、精简节点工作区、明确全局导航 | 桌面与手机首屏截图评审 |
| 视觉系统 | 中性色、青绿主色、语义状态色、统一图标和控件 | 亮色、暗色、焦点和对比度检查 |
| 用户流程 | 连接、节点、订阅、路由、设置、备份、日志 | Playwright 全流程回归 |
| 后端状态 | 版本、系统、架构、发行形态和能力信息 | API 与单元测试 |
| Docker | 普通代理、Linux TUN 两套 Compose 和 `/data` 契约 | 真实镜像与干净数据卷冒烟测试 |
| Deb | 内置 Node、systemd、CLI、数据保留 | amd64/arm64 构建和容器安装测试 |
| Windows | 直接运行、安装服务、卸载服务、动态端口 | ZIP 结构和批处理契约检查 |
| 仓库治理 | README、平台、安装、安全、升级、架构文档 | 链接和打包内容检查 |
| 发布 | Pages、GHCR、Deb、Windows ZIP、GitHub Release | 线上浏览器与产物检查 |
