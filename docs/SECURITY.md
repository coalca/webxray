# 安全边界

## Web 控制面

`config.json` 的 `authToken` 可以控制节点密钥、订阅、路由、Xray 进程和备份。它至少为
32 个字符，首次运行默认生成 64 位十六进制随机值。

- 不要提交或发送 `config.json`、`state.json` 和完整备份。
- 不要把 Web 端口直接暴露到不可信公网。
- 跨域独立前端只允许配置中明确列出的 `corsOrigins`。
- HTTPS 应由可信反向代理提供，WebXray 内置服务本身不终止 TLS。

## Mixed 代理

启用“允许局域网连接”后，Xray Mixed 入站监听 `0.0.0.0`。如果系统防火墙也放行该端口，
其他设备可以访问代理。需要共享时启用本地代理认证，并在防火墙中限制来源地址。

页面在“允许局域网连接”且未启用认证时显示安全提示。这个提示不能代替防火墙检查。

## TUN

TUN 和自动路由需要网络管理权限，可能改变宿主机所有流量的路径。远程服务器配置错误时
可能中断 SSH 或 Web 管理。Docker TUN 使用宿主网络，因此容器中的路由改动就是宿主路由
改动。

## 文件权限

Deb 服务使用独立 `webxray` 用户并将 `/var/lib/webxray` 权限设为 `0700`。Windows 服务
目录由主机管理员负责保护。Docker 绑定目录的权限由宿主机和容器运行用户共同决定。
